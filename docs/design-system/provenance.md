# Provenance

Design references were captured from platform.openai.com and distilled into `docs/design-system/tokens.json` and the component contract.

The shipped prototype source is framework-free: `vanilla/base.css`, `vanilla/design-system.js`, `vanilla/stories/`, and generated `tokens/`. Storybook HTML is the only review surface. No framework or third-party component CSS is part of runtime.
