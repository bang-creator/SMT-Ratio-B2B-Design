# Anti-slop rules

- No decorative sparkle or generic AI greeting on product surfaces.
- No suggestion chips with decorative icons unless the feature requires a real action.
- No oversized rounded-3xl composer; use the observed compact control geometry.
- No tool calls rendered as unexplained pills; expose status, action, and result.
- No invented context window percentage, fake confidence, or fabricated telemetry.
- No arbitrary gradients or brand colors outside semantic tokens.
